A responsive café website built during my Software Development Internship at Zool Tech Solutions, Bangalore (July 2024).

## ✨ Features
- Responsive layout that works on desktop, tablet and mobile
- Slide-out navigation menu
- Testimonial carousel
- Embedded Google Map
- Table-booking form

## 🧰 Tech stack
HTML5 · CSS3 · Bootstrap 5 · JavaScript

## 🎯 What I learned
- Translating design mockups into working front-end code
- Building responsive layouts with Bootstrap 5
- Adding interactive features (navigation, carousel, form) with JavaScript
- Delivering a complete project within a one-month internship
